GARCH Stock Volatility Analysis

Overview

This project explores stock market volatility using time-series analysis and a Generalised Autoregressive Conditional Heteroskedasticity (GARCH) model.

The analysis examines historical stock price movements, calculates financial returns, investigates volatility patterns, and applies GARCH modelling to capture changes in volatility over time. The project demonstrates the application of Python-based quantitative methods to a financial market problem.

Objectives

The main objectives of this project are to:

* Analyse historical stock price data.
* Calculate and examine daily stock returns.
* Explore the statistical characteristics of financial returns.
* Investigate volatility clustering in the return series.
* Apply a GARCH model to estimate time-varying conditional volatility.
* Visualise and interpret the estimated volatility.
* Develop practical experience in financial time-series modelling using Python.

Analysis and Methodology

The project follows a series of steps:

1. Data Preparation
   Historical stock price data are imported, organised, and prepared for analysis.

2. Exploratory Data Analysis
   Stock prices and trading-related variables are examined to understand their patterns and characteristics.

3. Return Calculation
   Daily returns are calculated from historical stock prices to provide a suitable series for volatility analysis.

4. Return Analysis
   The distribution and behaviour of the return series are examined to identify characteristics commonly observed in financial data.

5. Volatility Analysis
   The return series is analysed for evidence of volatility clustering, where periods of relatively high volatility tend to be followed by high volatility and periods of low volatility tend to be followed by low volatility.

6. GARCH Modelling
   A GARCH model is estimated to capture the time-varying nature of financial market volatility.

7. Model Interpretation
   The estimated conditional volatility is visualised and interpreted to understand changes in market risk over time.
